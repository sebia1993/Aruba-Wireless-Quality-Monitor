# 실장비 설정 구현 계획

[승인된 설계](../specs/2026-11-25-device-settings-design.md)를 기존 Windows 설치판에 적용한다. 앱이 열린 동안 수집하고 기존 운영 서비스의 데이터와 권한은 그대로 사용한다.

- [x] **장비 등록과 자격 증명**. device_profiles.py에 Windows 사용자별 원자적 저장, 최대 네 개의 프로필, 선택적 DPAPI 비밀번호, 기존 known_hosts와 별도로 확인한 SHA-256 지문을 검증하는 SSH 연결을 구현한다. 잘못된 키·계정에 자격 증명을 보내지 않는 시험과 프로필 편집·삭제 회귀 시험을 먼저 작성한다.
- [x] **실장비 조회**. device_monitor.py가 고정된 읽기 명령, 보호 로직과 ArubaOS 파서를 재사용해 관측 시각, CPU, AP, Radio, BSS, 명령별 상태를 생성한다. 세션 정리·실패 후 자동 인증 재시도 방지·결측과 0 구분을 시험한다.
- [x] **네이티브 설정 창**. device_window.py로 목록·등록·수정·삭제·테스트·저장하고 모니터링·중지 및 관측 목록을 제공한다. 네트워크 작업은 UI 스레드에서 분리하고 마지막 관측과 조회 상태를 표시한다.
- [x] **두 진입점**. desktop_app.py와 로컬 대시보드에 같은 설정 창으로 이동하는 동작을 추가한다. 브라우저의 요청은 창을 여는 데만 사용하고 민감한 정보는 네이티브 창에서 처리한다. 운영 주소 우선과 첫 실행·기존 장비 재실행을 시험한다.
- [x] **배포**. 단일 설치 파일로 Windows의 실제 창과 로컬 SSH 시험 장비를 확인하고 전체 테스트 및 서비스 회귀를 실행한다. 배포한 파일의 해시와 발송 링크를 확인하고 현장 미검증 범위를 릴리스 노트에 명시한다.

Windows 11 빌드 26200에서 최종 설치 파일로 장비 등록·자동 갱신·중지와 시작 메뉴 재실행을 확인했다. 로컬 SSH 시험 장비는 AP 1개, Radio 2개, SSID/BSSID 4개를 반환했다. 현장 장비 검증 상태와 SHA-256은 [v0.46.0 릴리스](https://github.com/sebia1993/Aruba-Wireless-Quality-Monitor/releases/tag/v0.46.0)에 기록했다.
