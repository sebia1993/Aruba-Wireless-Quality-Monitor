# Optional manual AP investigation reservations

Default disabled. With an approved client-validation manifest and the protected local config/manual-detail.json set to {"version":1,"enabled":true,"authorized":true}, operators/admins can reserve a read-only Client Table query from the selected currently attested persistent congestion Radio. Setting automatic=false in the client validation record disables automatic selection but does not prohibit this separately authorized manual Client Table reservation. Station Stats and Neighbor remain subject to their own approval rules. No free-form CLI, IP or MAC input is accepted.

The server only queues the target; it does not run SSH in an HTTP request. The worker checks active AP ownership, version/key, attestation lifetime, Radio/association/BSS freshness and controller protection again. Manual work is prioritized over young automatic detail work, with aging and unchanged base-poll priority. Both kinds share the same 5-AP Client Table pending/running cap and existing 20-job controller queue. A 180s deadline and 60s repeat cooldown apply; the queue position is approximate, not a promise.

Request IDs are scoped to the authenticated user and service instance. Retransmission returns the same receipt. If an active job already exists, the request joins it, and that receipt cannot cancel the shared automatic/other-user job. Cancellation is only for exclusively owned pending/deferred manual work. Running jobs are not interrupted. Receipt list is per user, bounded, held in memory; a restart invalidates its epoch and never replays work. Audit stores actor and opaque target/receipt reference, not raw clients. Completed means CLI parsed, not that downstream analysis or actual service impact is established. Client metrics remain subject to existing evidence/expiry gates.

Actual site operation remains unverified; this is a development feature, not a production release. Manual lookup of healthy APs, additional detail commands, durable restart receipt reconciliation and richer live job administration remain outstanding.

Manual submissions bind the wired AP identity to a local digest and recheck the active anchor plus current inventory before executing. The digest and raw MAC are not returned in receipts. A failed or invalid Client Table refresh invalidates the previous AP detail view. Joining an existing automatic job is not a fresh independent measurement.
