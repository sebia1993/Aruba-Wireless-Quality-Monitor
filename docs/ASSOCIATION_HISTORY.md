# Optional connection observations (v0.19)
Default disabled. This is pseudonymous personal data, not anonymous data. Enable only after actual field validation and internal privacy/retention approval. No collection of arbitrary credentials or device modifications.

The AOS 8 Users table is documented at https://arubanetworking.hpe.com/techdocs/CLI-Bank/Content/aos8/sh-user-tab.htm . The active and standby command scopes must be verified on the target model/firmware. Only positive associated tunnel rows are considered. Absence, a partial output or stale data never proves a disconnect, and UAC observations do not prove a seamless roaming event. An exact current BSSID/SSID/AP/physical Radio match and active AAC mapping is required. A-UAC/S-UAC observations are independent of AAC; conflicts suppress both. Separate direct AAA anchor query is still outstanding.

Provision the key once from `%ProgramFiles%\AWQM` under the designated service identity using `.\AWQM.exe --manager provision-history-key`. Protect the root and secrets ACLs. No key replacement or raw MAC lookup is offered. A lost key prevents future matching; do not silently recreate it. The DPAPI envelope is bound to the configured site.

Enable the previously approved retention policy. In protected config/association-history.json set version=1, enabled=true, authorized=true, site=<configured site>, contract="aos8-connection-history-v1", controllers=[records]. Each record requires controller, radio_tag (exact Radio approval hash), approved_at and valid_until (epoch seconds within Radio approval lifetime), reviewed_by (local reference), checks (all of active_association_mapping, bss_radio_mapping, active_table_uac_scope, standby_table_uac_scope, tunnel_forwarding_scope, privacy_approval, retention_approval). No example approval is valid in a real environment. {"version":1,"enabled":false} disables the path.

History records device, AP, physical Radio, BSS, network and context HMAC tokens, logical AP/controller IDs, band, observation interval and UAC evidence state. No MAC/IP/user name/SSID/BSSID plaintext is stored in association.db. Exact stable protected ID only; do not correlate random MAC changes. A change of AP, physical Radio, BSS or network starts an attachment-change segment. A Radio-only move can be observed on the same AP, band and BSS. Context and UAC changes also start segments. Repeated observations extend the last observation time. Gaps longer than 300 seconds start a new segment. These events record positive observations, with no inferred disconnect time or seamless roam.

The authenticated admin history query checks the current per-controller history approvals for both listings and exact-ID searches. A segment counts towards results and pagination only when its AAC has a current grant covering its recorded start. Each named active or standby UAC source also needs its own current grant covering that start. If one source loses approval, the other remains visible while authorized. If both positive sources are withheld, the displayed UAC state becomes unknown. A stored conflict contains no named sources. Expiry takes effect at query time. Removing a grant from the protected configuration takes effect when the service reloads it on restart.

A renewed grant with a later approval time does not disclose earlier segments under that grant. The next qualifying positive observation starts a new segment when the existing segment predates a participating controller’s grant. Existing database records and the independent 30-day retention schedule are preserved.

Admin-only authenticated audited API and UI. The query ceiling is 30 days and the approved daily retention removes expired segments in bounded batches and clips surviving start times. This DB is deliberately excluded from Radio/core archives, so its history is not restored with those backups. Host-level backups, filesystem/WAL and physical erasure are separate local controls. Leave retention enabled after stopping collection until historical rows are expired. Actual field coverage, privacy review and large-scale testing remain outstanding.
